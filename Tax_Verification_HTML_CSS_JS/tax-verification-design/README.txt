SECURITY VERIFICATION — VISUAL RECREATION

Open index.html directly in Google Chrome, Microsoft Edge or Firefox.
No installation, packages, build step, backend, or API key is required.
Keep index.html, styles.css and script.js in the same folder.

Layout recreates the supplied 1031-pixel screenshot: centered narrow content,
large white space, compact checkbox/brand card, and footer at the bottom.
The cloud mark is a locally drawn SVG approximation, not the official widget.

Clicking the checkbox runs a local animation and displays Demo verified.
Click again to reset. Privacy/Help opens an explanation dialog.

This is not Cloudflare Turnstile and does not perform verification, issue a
clearance cookie, solve CAPTCHA, or remove a challenge on another website.
The Ray ID is sample display text. It collects no credentials or user input.
The footer Cloudflare link opens its public website only when clicked.

For genuine security integration on a website you control, use the official
Cloudflare product and its documented server-side validation. This recreation
is intended for local UI/layout work, not as a security control.
